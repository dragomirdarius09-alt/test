\# TaskManager — Proiect Portofoliu



O aplicație care ajută utilizatorii să își organizeze taskurile zilnice.



\## Exemplu utilizator (JSON)



```json

{

&#x20; "id": 1,

&#x20; "nume": "Darius",

&#x20; "activ": true,

&#x20; "roluri": \["student", "intern"],

&#x20; "varsta": 21

}

```
